# Nisha's AI/ML Portfolio

This repository contains Nisha's personal portfolio website, built with React. It presents her education, skills, AI/ML interests, projects, achievements, and contact links in a responsive dark portfolio design.

## Built with

- React
- React Bootstrap and Bootstrap
- Framer Motion
- React Icons
- CSS

## Portfolio sections

- Home: professional introduction, education, and resume download
- About: background, interests, and development focus
- Skills: programming, AI/ML, data science, web, tools, and database skills
- Projects: compact project previews with animated full-detail modals
- Achievements and certificates
- Contact form and professional profile links

## Resume

The resume is stored at [`public/resume.pdf`](public/resume.pdf). Selecting **Download Resume** on the home section downloads the resume as `Nisha-Muthurajan-Resume.pdf`.

## Getting started

From the project directory:

```bash
npm install
npm start
```

The development site is available at [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

The optimized production files are generated in the `build` directory.

## Testing

```bash
npm test
```

## Project scripts

| Command | Purpose |
| --- | --- |
| `npm start` | Start the development server |
| `npm run build` | Create a production build |
| `npm test` | Run the test suite |
| `npm run eject` | Eject Create React App configuration |
